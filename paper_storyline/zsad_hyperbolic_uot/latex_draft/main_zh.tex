\title{面向 CLIP 零样本异常定位的可拒绝双曲正常性传输}
\author{匿名作者}
\date{}

\begin{document}
\maketitle

\begin{abstract}
基于 CLIP 的零样本异常定位通常比较图像 patch 与 normal/anomaly 文本提示的相似度，并由相对相似度生成异常分数。
这类方法有效利用了视觉语言模型的开放词汇能力，但相对相似度本身并不显式回答一个定位问题：某个局部视觉证据是否应被正常性参考接受。
本文提出双曲非平衡语义传输框架 \method{}，将 CLIP 零样本异常定位建模为 patch 到 AnomalyCLIP learned normal prompt 的可拒绝正常性匹配。
在该框架中，正常区域应以低代价被 normal prompt 锚点接受；难以被接受的区域则表现为高条件匹配代价或未匹配比例。
非平衡最优传输通过软化边缘质量约束提供可参数化的拒绝通道，使异常证据不必完全来自 anomaly prompt 的相对相似度。
双曲锥代价进一步把 learned normal prompt 从点原型扩展为锚点诱导的正常性接受域，刻画 patch 对该接受域的角度违背。
最终异常分数由未匹配比例和条件匹配代价共同组成。
实验部分将围绕质量松弛、双曲锥代价、normal prompt 锚点和异常信号分解检验该机制。

\end{abstract}

\section{引言}

零样本异常定位要求模型在缺少目标域异常样本的情况下识别异常图像并定位异常区域。
该任务在工业质检、医学影像和安全巡检中具有实际价值，因为异常模式通常稀缺、多样，并且很难在训练阶段完整枚举。
CLIP 等视觉语言模型通过大规模图文预训练获得了开放词汇图文对齐能力，为零样本异常检测提供了自然的语义接口 \needcite{CLIP}。
近期 CLIP 异常检测方法通常围绕正常和异常文本提示进行设计，将图像级或 patch 级视觉特征与文本特征比较，再把相似度转换为异常分数 \needcite{AnomalyCLIP, WinCLIP, PromptAD, APRILGAN, VAND}。
这种策略把异常检测转化为视觉语言相似度估计，因此能够在目标异常样本不足时保持较强迁移能力。

然而，独立的 patch-wise prompt scoring 只给出局部特征与文本原型之间的相对相似度。
当一个 patch 同时不像 normal prompt、也没有稳定地贴近 anomaly prompt 时，相对打分仍会把它压缩成 normal/anomaly 二元比较。
对于异常定位，更关键的问题是该 patch 是否仍可被正常性参考接受：若局部证据无法被正常 prompt 以低代价解释，它本身就构成异常线索。
这里的重点不是声称 anomaly prompt 比 normal prompt 更粗粒度，而是指出二元相似度缺少一个显式的接受/拒绝变量。
本文因此把异常证据定义为正常性匹配失败，而不是仅定义为 anomaly prompt 相似度更高。

本文从这一观点出发，为 CLIP 零样本异常定位提出一种 patch-to-normality 非平衡匹配机制。
给定图像 patch 特征和 AnomalyCLIP 已学习的 normal prompt 锚点，正常区域应被该锚点低代价接受。
若一个 patch 的传输代价较高，模型不应仅因为质量守恒约束而把它完整分配给 normal prompt。
这类区域可以体现为两种信号：已有匹配仍然代价较高，或只有部分质量被 normal prompt 接受。
因此，本文关注的不是替换 normal/anomaly prompt，而是在 CLIP prompt scoring 之上增加一个可观测的正常性接受失败变量。

最优传输为分布匹配提供了经典工具 \needcite{OptimalTransport}。
如果把 patch 视为源分布，把正常性锚点视为目标分布，传输计划可以刻画局部视觉证据如何匹配到正常性锚点。
但标准平衡最优传输要求源端和目标端质量完全守恒，这意味着每个 patch 的质量都必须被分配到 normal prompt 锚点。
在异常定位中，这一约束会抹去“该 patch 不应被正常性接受”的可能性。
非平衡最优传输通过散度惩罚软化边缘分布约束，允许质量发生增减 \needcite{UnbalancedOptimalTransport, Sinkhorn}。
这为模型提供了一个可参数化的软拒绝通道：无法以合理代价传输到 normal prompt 的 patch 不必被完整匹配。
本文将由此得到的未匹配比例作为异常证据的一部分，并在机制实验中单独检验它与异常区域的对应关系。

这种匹配机制还使代价矩阵成为方法的核心。
若代价只是 CLIP 特征之间的余弦或欧氏距离，learned normal prompt 仍只是平坦空间中的点原型。
异常定位中的正常性判断更接近一个接受域问题：patch 不仅要靠近 normal prompt，还应落在该锚点诱导的正常性方向约束内。
双曲空间常被用于表示层级、包含和蕴含式关系 \needcite{PoincareEmbeddings, HyperbolicNeuralNetworks, HyperbolicVisionLanguage}。
本文使用双曲锥代价把 normal prompt 锚点扩展为接受锥：锥内区域对应可接受的正常性解释，锥外偏离对应正常性约束违背。
这样，双曲空间在本文中承担明确角色：它定义 patch-to-normality 传输的结构化代价，而不是单独替换特征距离。

基于上述动机，本文提出 \method{}，即面向 CLIP 零样本异常定位的双曲非平衡语义传输框架。
方法首先从 CLIP 或 CLIP 异常模型中提取 patch 特征和正常性文本锚点，并在双曲空间中构造语义代价矩阵。
随后求解非平衡最优传输，得到 patch 到正常性锚点的软匹配计划。
每个 patch 的异常分数由未匹配比例和条件匹配代价组成，前者表示匹配不足，后者表示困难匹配。
通过这一流程，正常性接受失败从隐含的相似度差值变成了可分解、可视化、可消融的 anomaly scoring 变量。

本文贡献可以概括为以下三点：
\begin{enumerate}[leftmargin=*]
    \item 本文提出一种面向 CLIP 零样本异常定位的可拒绝 patch-to-normality 匹配机制，使异常证据能够通过条件匹配代价和未匹配比例显现。
    \item 本文以 AnomalyCLIP learned normal prompt 为正常性锚点，并用双曲锥代价将该锚点实例化为结构化正常性接受域。
    \item 本文构造非平衡语义传输分数，将未匹配比例、条件匹配代价及其组合用于像素级异常定位，并设计相应机制消融。

\section{相关工作}

\subsection{基于 CLIP 的零样本异常定位}

CLIP 异常检测方法利用视觉语言预训练模型的图文对齐能力，在缺少目标异常样本时构造可迁移的异常分数 \needcite{CLIP, ZSADSurvey}。
常见做法是设计正常和异常文本提示，提取图像 patch 特征，并用视觉文本相似度生成图像级或像素级 anomaly map \needcite{WinCLIP, AnomalyCLIP, PromptAD}。
后续方法进一步引入 prompt learning、局部视觉特征聚合、对象无关提示或多尺度区域对齐，以提升跨类别迁移和定位能力 \needcite{APRILGAN, VAND}。

本文关注的是这类方法中的打分表述。
现有方法通常把 patch 独立比较到正常和异常文本原型，异常分数来自二者的相对关系。
这一机制在实践中有效，但没有显式表达“该 patch 是否应被 normal prompt 接受”。
本文沿用 AnomalyCLIP learned normal prompt 作为正常性参考，并在其上引入非平衡传输，使异常分数包含未匹配比例和条件匹配代价。

\subsection{双曲表征与视觉语言结构}

双曲空间由于负曲率几何特性，适合低失真表示树状和层级关系 \needcite{PoincareEmbeddings, HyperbolicNeuralNetworks}。
在计算机视觉和视觉语言学习中，双曲几何已被用于类别层级建模、视觉蕴含、图文对齐和结构化语义推理 \needcite{HyperbolicVision, HyperbolicCLIP}。
异常检测中也存在利用双曲距离、双曲表征或双曲 prompt 的相关尝试 \needcite{HyperbolicAnomaly}。

本文使用双曲几何定义 normal prompt 锚点诱导的接受域。
与直接使用双曲距离不同，双曲锥代价关注 patch 是否偏离锚点的正常性方向约束。
这一设计把 learned normal prompt 从单个点原型转化为可用于传输匹配的结构化代价函数。

\subsection{最优传输、非平衡传输与未匹配比例}

最优传输通过最小化分布之间的匹配代价来比较两个分布 \needcite{OptimalTransport}。
它已被用于视觉匹配、域适应、表示学习和视觉语言对齐等任务 \needcite{OTVision, OTVL}。
标准平衡最优传输要求所有源质量和目标质量完全匹配；部分最优传输允许匹配固定比例的质量；非平衡最优传输则通过 KL 散度或其他散度项软化边缘约束 \needcite{PartialOT, UnbalancedOptimalTransport, Sinkhorn}。

异常定位天然需要拒绝机制。
如果测试图像包含异常区域，强制每个 patch 都匹配到正常锚点可能导致过度匹配。
因此，本文使用 UOT 得到一个显式的质量松弛变量，而不把传输仅作为 anomaly map 后处理。
该变量与条件匹配代价共同构成本文的异常证据，并可通过信号分解和可视化进行检验。

\subsection{一类异常检测与开放集识别}

一类异常检测通常只建模正常分布，并把偏离正常分布的样本视为异常 \needcite{OneClassAD}。
开放集识别也要求模型拒绝不属于已知类别的样本 \needcite{OpenSetRecognition}。
本文与这些工作共享“由正常性定义判别边界”的思想，但工作场景不同。
本文没有依赖目标域正常样本来学习密度模型，而是利用 CLIP 特征和 AnomalyCLIP learned normal prompt 在零样本设定下定义正常性参考。

\section{方法}

\subsection{问题定义}

给定测试图像 $x$，CLIP 图像编码器或 CLIP-based anomaly model 提取 $N$ 个 patch 特征：
\begin{equation}
    P = \{p_i\}_{i=1}^{N}, \qquad p_i \in \mathbb{R}^{d}.
\end{equation}
AnomalyCLIP 的文本编码器和 prompt learner 产生 $M$ 个 learned normal prompt 锚点：
\begin{equation}
    T = \{t_j\}_{j=1}^{M}, \qquad t_j \in \mathbb{R}^{d}.
\end{equation}
当前主实现采用 \texttt{anchor\_mode=normal}，即使用 learned normal text feature 作为正常性锚点；公式保留 $M$ 个锚点的写法，以覆盖 prompt learner 输出多个 normal variants 的情形。
目标是为每个 patch 生成异常分数 $s_i$，并上采样为像素级 anomaly map。
零样本设定假设推理时没有目标类别异常样本，也不使用目标异常 mask 调参。

\subsection{正常性锚点}

正常性锚点为 patch 提供可匹配的正常性参考。
本文主方法只使用 AnomalyCLIP 已学习的 normal prompt 特征，不额外引入手工编写的 normality bank，也不使用类别条件文本作为主方法组成。
这一选择使方法继承已有 CLIP 异常模型的 prompt learning 能力，同时把本文的新增部分限定为传输匹配和代价设计。

为避免锚点来源带来混杂，所有主实验固定使用相同的 learned normal prompt。
锚点相关实验只作为负对照：例如将 normal anchor 替换为 learned anomaly prompt、同时使用 normal/anomaly anchors，或使用打乱后的 normal feature。
这些对照用于检验性能是否来自正常性锚点本身，而不是来自锚点数量或传输超参数。

\subsection{双曲正常性代价}

UOT 需要 patch 到锚点的代价矩阵 $C \in \mathbb{R}^{N \times M}$。
本文将归一化的视觉特征和文本特征映射到曲率为 $c$ 的 Poincare ball $\mathbb{B}_{c}^{d}$：
\begin{equation}
    z_i = \operatorname{Exp}^{c}_{0}(p_i), \qquad
    u_j = \operatorname{Exp}^{c}_{0}(t_j),
\end{equation}
其中 $\operatorname{Exp}^{c}_{0}(\cdot)$ 是原点处的指数映射。
一种直接代价是双曲距离：
\begin{equation}
    C_{ij}^{\mathrm{dist}} = d_{\mathbb{B}_{c}}(z_i, u_j).
\end{equation}
它衡量 patch 与正常性锚点在曲率空间中的距离。

另一种代价把 learned normal prompt 视为正常性接受锥的锚点：
\begin{equation}
    C_{ij}^{\mathrm{cone}} = V\left(z_i, \operatorname{Cone}(u_j)\right).
\end{equation}
其中 $V(\cdot)$ 衡量 patch 相对锚点外向轴的角度偏离是否超过锥孔径。
当 patch 落在 normal prompt 诱导的接受锥内时，该代价较低；当 patch 偏离该正常性方向约束时，代价升高。
因此，双曲锥代价不是简单替换余弦距离，而是把 normal prompt 从点原型扩展为带方向约束的接受域。

\subsection{非平衡语义传输}

令 $a \in \mathbb{R}_{+}^{N}$ 表示 patch 端质量，$b \in \mathbb{R}_{+}^{M}$ 表示锚点端质量。
平衡最优传输求解：
\begin{equation}
    \min_{\gamma \geq 0} \langle \gamma, C \rangle
    \quad
    \mathrm{s.t.}\quad
    \gamma \mathbf{1}_{M}=a,\quad
    \gamma^{\top}\mathbf{1}_{N}=b,
\end{equation}
其中 $\gamma \in \mathbb{R}_{+}^{N \times M}$ 是传输计划。
这一形式要求每个 patch 端质量都被传输。
对于异常定位，这会把异常区域也强制匹配到正常性锚点。

本文使用熵正则非平衡最优传输：
\begin{equation}
\begin{split}
    \min_{\gamma \geq 0} \quad
    &\langle \gamma, C \rangle
    + \tau_{p} D_{\mathrm{KL}}(\gamma \mathbf{1}_{M} \,\|\, a) \\
    &+ \tau_{t} D_{\mathrm{KL}}(\gamma^{\top}\mathbf{1}_{N} \,\|\, b)
    + \epsilon \Omega(\gamma),
\end{split}
\label{eq:uot}
\end{equation}
其中 $\Omega(\gamma)=\sum_{ij}\gamma_{ij}(\log \gamma_{ij}-1)$。
$\tau_p$ 和 $\tau_t$ 控制 patch 端和锚点端质量守恒强度。
当它们较大时，问题接近平衡传输；当它们较小时，传输计划允许更多质量变化。
这一质量松弛给出了本文的软拒绝项：不能与 normal prompt 低代价匹配的 patch 可以只传输部分质量。
本文显式读取未传输部分，并通过信号分解实验检验其作为异常证据的作用。

\subsection{异常分数}

对第 $i$ 个 patch，传输后的匹配质量为：
\begin{equation}
    m_i = \sum_{j=1}^{M} \gamma_{ij}.
\end{equation}
未匹配质量定义为：
\begin{equation}
    u_i = \max(a_i - m_i, 0).
\end{equation}
未匹配比例为：
\begin{equation}
    r_i = \frac{u_i}{a_i+\delta}.
\end{equation}
匹配代价定义为：
\begin{equation}
    q_i =
    \frac{\sum_{j=1}^{M} \gamma_{ij} C_{ij}}{m_i + \delta},
\end{equation}
其中 $\delta$ 为数值稳定常数。
最终异常分数为：
\begin{equation}
    s_i = \alpha r_i + \beta \,\operatorname{Norm}(q_i).
\end{equation}
未匹配比例表示 patch 未被正常性锚点充分匹配的程度，匹配代价表示已有匹配仍需要付出的语义成本。
二者分别对应“匹配不足”和“高代价匹配”两类异常证据。

\subsection{推理复杂度与可补充性质}

UOT 可通过 Sinkhorn 风格迭代求解。
若 patch 数为 $N$，锚点数为 $M$，迭代次数为 $K$，则特征提取后的主要复杂度为 $O(KNM)$。
因此，本文方法需要保持锚点库紧凑，并报告相对普通 prompt scoring 的推理开销。

\section{实验设计与待填结果}

本文初稿不写入任何实验结论。
本节规定用于支撑本文机制叙事的主实验、消融实验和可视化证据。

\subsection{实验问题}

实验应回答四个问题：
\begin{enumerate}[leftmargin=*]
    \item 质量松弛是否必要，即 UOT 是否优于无传输、平衡传输和部分传输？
    \item 在相同 UOT 设置下，双曲正常性代价是否优于余弦和欧氏代价？
    \item 未匹配比例本身是否与真实异常区域对齐？
    \item AnomalyCLIP learned normal prompt 是否比 anomaly prompt 或错配 normal feature 更适合作为正常性接受锚点？
\end{enumerate}

\subsection{数据集、协议与指标}

主实验至少应包含 MVTec AD 和 VisA \needcite{MVTecAD, VisA}。
若时间允许，可加入 MPDD、BTAD、SDD、DAGM 或医学异常检测数据集，用于检验跨域稳定性。
协议应与所比较的 CLIP-based baseline 保持一致，尤其是训练数据、prompt 设置、图像分辨率、feature layer 和后处理步骤。

标准指标包括 pixel AUROC、pixel AUPRO、image AUROC 和 image AP。

\section{讨论}

本文的核心叙事是把正常性匹配失败显式纳入 CLIP 零样本异常定位的 anomaly scoring。
在这一表述中，CLIP 提供局部视觉特征，AnomalyCLIP learned normal prompt 定义正常性参考，双曲锥代价定义锚点诱导的接受域，UOT 则估计每个 patch 的传输质量和条件匹配代价。
未匹配比例因此成为一个可检查的机制变量，而不是单纯的后处理分数。

这一设计把异常定位中的两个信号分开处理。
条件匹配代价描述 patch 被 normal prompt 接受时需要付出的代价；未匹配比例描述 patch 在质量松弛下未被充分接受的程度。
二者的分解使论文能够分别分析“难以正常解释”和“被正常性拒绝”两类异常证据，并通过可视化和消融检查二者是否互补。

\section{局限性}

第一，本文依赖 AnomalyCLIP learned normal prompt 的质量。
如果该 prompt 本身没有形成稳定的正常性参考，传输计划也难以产生可靠的接受/拒绝信号。
因此，锚点负对照是本文实验设计中的必要组成。

第二，双曲锥代价需要与平坦代价严格区分。
CLIP 特征经过指数映射后不必然具有可利用的双曲结构；本文的关键检验是锥违背代价是否比余弦、欧氏或双曲距离更好地刻画 normal prompt 的接受域。

第三，UOT 引入额外超参数和推理开销。
如果 $\tau_p$、$\tau_t$、$\epsilon$、curvature 或 anchor count 需要针对每个数据集细调，则方法的零样本属性和实用价值会被削弱。

第四，相关工作边界需要严格核验。
本文不应把 OT、UOT、双曲空间或 CLIP 异常检测写成本文独有贡献。
本文的主张边界是：在 AnomalyCLIP learned normal prompt 上构造可拒绝的 patch-to-normality 传输打分，并以未匹配比例和条件匹配代价检验正常性接受失败是否能作为异常证据。

\section{结论}

本文提出面向 CLIP 零样本异常定位的可拒绝双曲正常性传输框架。
该框架把异常定位建模为带软拒绝通道的正常性匹配：正常 patch 应能被 AnomalyCLIP learned normal prompt 低代价接受，异常 patch 则表现为高条件匹配代价或未匹配比例。
方法上，本文用双曲锥代价定义 normal prompt 的接受域，并用非平衡最优传输产生可分解的异常证据。
