\title{面向 \clip{} 零样本异常定位的可拒绝双曲正常性接收}
\author{匿名作者}
\date{}

\begin{document}
\maketitle

\begin{abstract}
\clip{} 零样本异常定位通常沿用图文匹配的闭集比较语法：为 normal 与 anomaly 构造文本提示，再由 patch--text 相似度差生成异常图。
本文主张，这一语法并不是该任务的正确基本单位。
工业缺陷很少构成稳定、可枚举的异常语义类；它们更准确地表现为正常外观、材料状态和结构约束在局部证据上的失效。
因此，异常 patch 的定义不在于它是否更接近通用的 ``abnormal'' 文本，而在于它是否仍是 learned normal concept 的合法特化。
基于这一任务重构，本文提出可拒绝双曲正常性接收框架 \method{}。
\method{} 将 AnomalyCLIP 的 learned normal prompt 解释为语义可接收性锚点，而不是正常类中心；normal concept 到 patch 的接收关系是非对称的，normal concept 约束哪些局部证据可被视为正常，patch 不能反向定义 normal concept。
基于这一非对称性，\method{} 用双曲锥刻画从 normal anchor 指向可接收局部证据的方向性合法特化关系，并通过非平衡最优传输实现 patch 级可拒绝接收。
该推断过程给出两个具有明确含义的异常证据：未接收比例刻画局部证据被正常性拒绝的程度，条件接收代价刻画已接收证据仍付出的解释成本。
在 MVTec AD 和 VisA 上，\method{} 在像素级定位上取得一致提升；传输模式、代价形式、锚点替换和证据分解实验进一步对应验证了正常性接收命题导出的四项机制预期。
\end{abstract}

\noindent\textbf{关键词：} 零样本异常定位；视觉语言模型；正常性接收；语义可接收性；双曲几何；非平衡最优传输

\section{引言}

零样本异常定位的难点并不止于缺少异常样本。
更根本的困难在于，异常本身不是一个稳定的语义类别。
工业质检、医学影像和安全巡检中的缺陷具有开放形态：同一对象上的划痕、压痕、污染、缺口、边缘破损和材料变色共享的并非某个可命名语义，而是对正常外观与结构约束的局部破坏。
\clip{} 的视觉语言预训练提供了开放词表接口，使模型能够通过文本提示构造跨类别判别函数 \cite{CLIP}。
现有 \clip{} 异常定位方法据此构造 normal/anomaly prompts，将局部视觉特征与文本特征进行相似度比较，并由相似度差生成像素级异常图 \cite{AnomalyCLIP, WinCLIP, PromptAD, APRILGAN, VAND}。
这一范式有效利用了 \clip{} 的跨模态对齐能力，却同时继承了闭集识别中的对称比较假设：normal 与 anomaly 被当作两个可并列竞争的文本语义。

本文的出发点是：\clip{} 零样本异常定位的基本对象不是异常语义类，而是 normal concept 对局部证据的语义可接收性。
异常 patch 不必比 normal patch 更接近通用的 ``abnormal'' 文本。
它之所以成为异常，是因为它不再是 learned normal concept 的合法特化，正常性参考无法用低代价解释它。
这一重构把 anomaly scoring 从“正常/异常文本分类”转化为“局部证据是否仍被正常概念接收”的判别。
在该视角下，模型不再试图穷举异常的名称，而是估计正常性在何处失去解释力。

这一命题重新定义了 learned normal prompt 的角色。
在 prompt scoring 中，normal prompt 通常只是二分类比较中的一个文本原型。
在正常性接收中，它是语义可接收性锚点：它不是正常类中心，而是规定哪些局部证据可作为该正常概念的合法特化。
正常 patch 沿着该锚点诱导的可接收方向被解释；异常 patch 则表现为方向违背或接收失败。
接收失败具有两种可分解形态。
一类证据不再满足正常概念到局部证据的合法特化关系，形成未接收质量；另一类证据仍被接收，却伴随较高解释代价。
前者对应显式拒绝，后者对应困难接收。
两者共同构成异常定位中比单一相似度差更可审计的证据结构。

正常性接收还要求 normal prompt 从点式原型升级为方向性接收锚点。
将 normal prompt 视为正常类中心时，欧氏球、余弦邻域或双曲距离只能表达“靠近正常”。
但 CLIP-ZSAD 中的 learned normal prompt 更接近一个正常概念约束：它描述“正常表面”“正常边界”或“正常材料状态”可以接受哪些局部表现，而不是枚举这些表现的中心。
这种关系是非对称的：normal concept 约束 patch 是否可作为其合法特化，patch 不能反向定义 normal concept。
点到点距离无法表达这种从语义锚点到局部证据的方向性可接收关系。
双曲几何适合表示层级和蕴含式关系 \cite{PoincareEmbeddings, HyperbolicNeuralNetworks, HyperbolicVisionLanguage}；其中锥结构能够把锚点到实例的非对称约束显式化。
本文因此将 learned normal prompt 解释为双曲空间中的语义可接收锥：锥内区域表示 normal anchor 允许的局部特化，锥外偏离表示方向性违背，而不是单纯距离变远。

最后，正常性接收必须具备拒绝机制。
在平衡匹配中，所有 patch 质量都会被分配给某个 normal anchor，缺陷区域也被强行解释为正常证据。
非平衡最优传输通过软化边缘质量约束允许质量不守恒 \cite{UnbalancedOptimalTransport, Sinkhorn}，正好提供了 patch 级拒绝变量。
在本文中，UOT 不是附加的匹配模块，而是正常性接收命题的推断形式：低代价证据被接收，无法被解释的证据保留为未接收质量。

基于上述任务重构，本文提出 \method{}，即 Rejectable Hyperbolic Normality Acceptance。
\method{} 使用 \clip{}/AnomalyCLIP 提取 patch 特征，以 learned normal prompt 构建语义可接收性锚点，通过双曲锥代价刻画方向性合法特化，并用 UOT 估计每个 patch 的接收状态。
这一命题直接推出四项可观测预期：可拒绝接收优于强制接收；双曲锥优于点式距离，因为异常体现为方向性违背而不只是远离锚点；未接收比例与条件接收代价提供互补证据；learned normal prompt 优于 anomaly 或错配锚点。
本文的实验围绕这些预期组织，并将每项结果对应到可观察的接收状态。

本文贡献如下：
\begin{enumerate}[leftmargin=*]
    \item 提出 \clip{} 零样本异常定位的可拒绝正常性接收命题，将异常从可枚举语义类重写为不能作为 learned normal concept 合法特化的局部证据。
    \item 提出双曲语义可接收锥，将 learned normal prompt 从点式文本原型提升为语义可接收性锚点，并用锥内包含刻画 normal concept 到 patch 的方向性合法特化。
    \item 提出基于非平衡最优传输的可拒绝接收推断，并将异常证据分解为未接收比例和条件接收代价两个可观测量。
\end{enumerate}

\section{相关工作}

\subsection{基于视觉语言模型的零样本异常定位}

基于 \clip{} 的异常定位方法利用图文对齐能力缓解目标域异常样本缺失问题。
典型方法构造正常和异常文本提示，将图像级或 patch 级视觉特征映射到文本语义空间，并由视觉--文本相似度生成异常分数 \cite{WinCLIP, AnomalyCLIP, PromptAD}。
后续工作通过 prompt learning、局部特征对齐、多尺度融合和对象无关提示进一步增强跨类别泛化 \cite{APRILGAN, VAND}。

本文继承这一路线中最有价值的部分，即 learned normal prompt 对跨类别正常性的抽象能力，同时改变其判别角色。
在 \method{} 中，normal prompt 不是与 anomaly prompt 竞争的分类原型，而是定义局部证据合法特化范围的语义可接收性锚点。
这一转变使异常分数从相对相似度扩展为显式的接收状态估计。

\subsection{双曲表征与结构化语义}

双曲空间因负曲率结构而适合表示层级、包含和蕴含关系 \cite{PoincareEmbeddings, HyperbolicNeuralNetworks}。
在视觉和视觉语言任务中，双曲几何已用于类别层级建模、视觉蕴含、跨模态对齐和结构化语义推理 \cite{HyperbolicVision, HyperbolicCLIP}。
异常检测中也存在使用双曲距离或双曲表征的相关工作 \cite{HyperbolicAnomaly}。

在 \method{} 中，双曲几何承担语义可接收性的结构角色。
本文使用双曲锥刻画 normal prompt 诱导的语义可接收性，使几何结构服务于正常概念到局部证据的非对称约束。
这种设计关注 patch 是否是 normal anchor 的合法特化，而不只是距离某个文本点的远近。

\subsection{最优传输与拒绝式推断}

最优传输通过最小化分布间耦合代价来比较两个分布 \cite{OptimalTransport}，并已广泛用于视觉匹配、域适应、表示学习和视觉语言对齐 \cite{OTVision, OTVL}。
标准平衡 OT 保持源端和目标端质量守恒；部分 OT 匹配预设比例的质量；UOT 则以散度项软化边缘约束 \cite{PartialOT, UnbalancedOptimalTransport, Sinkhorn}。

异常定位天然包含显式拒绝能力。
当测试图像包含缺陷区域时，严格质量守恒会把所有 patch 解释为某种正常性证据，导致过度接收。
\method{} 使用 UOT 将质量松弛转化为 patch 级拒绝变量，并将该变量与条件接收代价共同用于异常定位。

\subsection{一类建模与开放集识别}

一类异常检测以正常数据建立判别边界，并将偏离正常分布的样本识别为异常 \cite{OneClassAD}。
开放集识别同样要求模型拒绝不属于已知类别的样本 \cite{OpenSetRecognition}。
\method{} 与这些思想共享“由正常性定义接受集合”的原则，但它不依赖目标域正常样本来估计密度。
本文在 \clip{} 零样本设定下，通过 learned normal prompt、双曲语义可接收锥和可拒绝传输构造 patch 级正常性接收函数。

\section{方法}

\subsection{从相似度分类到正常性接收}

给定测试图像 $x$，视觉编码器提取 $N$ 个 patch 特征：
\begin{equation}
    P = \{p_i\}_{i=1}^{N}, \qquad p_i \in \mathbb{R}^{d}.
\end{equation}
AnomalyCLIP 的文本编码器和 prompt learner 产生 $M$ 个 learned normal prompt 特征：
\begin{equation}
    T = \{t_j\}_{j=1}^{M}, \qquad t_j \in \mathbb{R}^{d}.
\end{equation}
主设定使用 \texttt{anchor\_mode=normal}，即仅使用 learned normal prompt 作为正常性锚点。
目标是在零样本条件下为每个 patch 估计异常分数 $s_i$，并上采样得到像素级 anomaly map。

\method{} 将 $T$ 解释为语义可接收性参考。
当 $p_i$ 可作为 $T$ 的低代价合法特化被接收时，该 patch 倾向于正常；当 $p_i$ 违背该可接收方向、被拒绝或仅能高代价接收时，该 patch 提供异常证据。
因此，本文估计的是 patch 的正常性接收状态，而不是它与 abnormal prompt 的相对相似度。
这一设定保留 \clip{} 的开放词表优势，同时避免把开放异常压缩成一个固定异常词义。

\subsection{双曲语义可接收锥}

首先将归一化后的视觉特征和文本特征映射到曲率为 $c$ 的 Poincare ball $\mathbb{B}_{c}^{d}$：
\begin{equation}
    z_i = \operatorname{Exp}^{c}_{0}(p_i), \qquad
    u_j = \operatorname{Exp}^{c}_{0}(t_j),
\end{equation}
其中 $\operatorname{Exp}^{c}_{0}(\cdot)$ 为原点处指数映射。
作为点式几何基线，双曲距离代价定义为
\begin{equation}
    C_{ij}^{\mathrm{dist}} = d_{\mathbb{B}_{c}}(z_i, u_j).
\end{equation}
该基线仍然把 $u_j$ 当作点式原型，只衡量 $z_i$ 与 $u_j$ 的邻近性。
对于正常性接收，关键关系不是邻近，而是 $z_i$ 是否沿着 $u_j$ 诱导的可接收方向成为 normal concept 的合法特化。

\method{} 的主代价为双曲锥违背代价：
\begin{equation}
    C_{ij}^{\mathrm{cone}} =
    V\!\left(z_i, \operatorname{Cone}(u_j)\right).
\end{equation}
$\operatorname{Cone}(u_j)$ 表示由 normal anchor $u_j$ 诱导的语义可接收锥，$V(\cdot)$ 度量 patch 相对于锥轴和锥孔径的方向性偏离。
当 $z_i$ 落在锥内时，$p_i$ 被视为该 normal concept 的合法局部特化；当 $z_i$ 偏离锥体时，它不仅远离某个点，而是违背了 normal anchor 对局部证据的可接收方向。
因此，normal prompt 在 \method{} 中不是单个最近邻原型，而是带有非对称约束的语义可接收性锚点。

\subsection{可拒绝接收推断}

令 $a \in \mathbb{R}_{+}^{N}$ 为 patch 端质量，$b \in \mathbb{R}_{+}^{M}$ 为锚点端质量。
平衡 OT 求解
\begin{equation}
    \min_{\gamma \geq 0} \langle \gamma, C \rangle,
    \qquad
    \gamma \mathbf{1}_{M}=a,\quad
    \gamma^{\top}\mathbf{1}_{N}=b,
\end{equation}
其中 $\gamma \in \mathbb{R}_{+}^{N \times M}$ 为耦合计划。
该约束要求每个 patch 的质量都被 normal anchors 接收。
对于异常定位，这一约束会系统性地过度解释缺陷区域。

\method{} 使用熵正则 UOT：
\begin{equation}
\begin{split}
    \min_{\gamma \geq 0} \quad
    &\langle \gamma, C \rangle
    + \tau_{p} D_{\mathrm{KL}}(\gamma \mathbf{1}_{M} \,\|\, a) \\
    &+ \tau_{t} D_{\mathrm{KL}}(\gamma^{\top}\mathbf{1}_{N} \,\|\, b)
    + \epsilon \Omega(\gamma),
\end{split}
\label{eq:uot}
\end{equation}
其中 $\Omega(\gamma)=\sum_{ij}\gamma_{ij}(\log \gamma_{ij}-1)$。
$\tau_p$ 和 $\tau_t$ 控制 patch 端和锚点端的质量保持强度，$\epsilon$ 控制熵正则强度。
较大的 $\tau_p,\tau_t$ 使解接近平衡接收；较强的质量松弛允许无法低代价满足可接收方向的 patch 保留未接收质量。
由此，UOT 的边缘松弛在 \method{} 中具有直接语义：它不是数值技巧，而是正常性接收中的拒绝通道。

\subsection{异常证据分解}

对 patch $i$，被正常性接收的质量为
\begin{equation}
    m_i = \sum_{j=1}^{M} \gamma_{ij}.
\end{equation}
未接收质量和未接收比例分别定义为
\begin{equation}
    u_i = \max(a_i - m_i, 0), \qquad
    r_i = \frac{u_i}{a_i+\delta}.
\end{equation}
条件接收代价定义为
\begin{equation}
    q_i =
    \frac{\sum_{j=1}^{M} \gamma_{ij} C_{ij}}{m_i + \delta},
\end{equation}
其中 $\delta$ 为数值稳定常数。
最终 patch 级异常分数为
\begin{equation}
    s_i = \alpha r_i + \beta \,\operatorname{Norm}(q_i).
\end{equation}
$r_i$ 描述 patch 被正常性拒绝的程度；$q_i$ 描述 patch 在被接收条件下仍付出的解释代价。
这两个量分别对应拒绝式证据和困难接收证据。
前者突出不可解释的局部偏离，后者突出可被勉强解释但代价异常的结构偏离。

\subsection{复杂度}

UOT 采用 Sinkhorn 式迭代求解。
给定 patch 数 $N$、锚点数 $M$ 和迭代步数 $K$，特征提取后的主要计算复杂度为 $O(KNM)$。
由于主设定仅使用 learned normal prompts，锚点数保持较小，额外开销主要来自轻量的耦合迭代。

\section{实验}

\subsection{命题验证协议}

实验部分以正常性接收命题的可观测后果为组织单位。
第一，可拒绝接收相对于强制接收产生更低 over-match 和更高定位质量。
第二，双曲语义可接收锥相对于平坦代价和点式双曲距离产生更清晰的方向性接收边界。
第三，未接收比例与条件接收代价捕获不同异常证据，二者组合优于任一单项。
第四，learned normal prompt 是正常性接收的正确参考，anomaly prompt 或错配 normal anchor 会破坏接收语义。

实验在 MVTec AD 和 VisA 上评估 \method{} \cite{MVTecAD, VisA}。
所有比较方法使用一致的图像分辨率、特征层、prompt 设定和后处理流程。
主指标包括 Pixel AUROC、Pixel AUPRO 和 Image AUROC。
除标准指标外，本文报告未接收比例 AUC、异常/正常区域未接收比例差异、条件接收代价差异、over-match rate 和 normal-image FPR，用于直接观察接收状态本身。

\subsection{总体定位能力}

表 \ref{tab:main} 比较 \method{} 与 prompt scoring、AnomalyCLIP、无 UOT 的双曲锥打分以及不同 UOT 代价。
主结果回答一个整体问题：当异常被建模为正常性接收失败时，定位质量是否在完整推断链条上提升。
\method{} 在 MVTec AD 和 VisA 上均取得最佳像素级结果，其中 Pixel AUPRO 的提升最为突出。
这说明 \method{} 的主要收益落在局部区域和边界定位，而不是仅来自图像级语义判别增强。

\section{讨论}

\method{} 的意义不在于把双曲几何与 UOT 并置，而在于改变 \clip{} 零样本异常定位的判别对象。
Prompt scoring 试图回答“这个 patch 更像 normal 还是 abnormal”；\method{} 回答“这个 patch 是否仍能被正常性低代价接收”。
二者的差别决定了方法设计的顺序。
先有正常性接收命题，才有 normal prompt 的语义可接收性锚点化、双曲锥的方向性合法特化关系，以及 UOT 的拒绝变量。

从实验回看，四组机制分析形成了同一条证据链。
传输模式比较表明，严格质量守恒带来过度接收，而 UOT 的质量松弛产生稳定拒绝信号。
代价比较表明，双曲锥优于点式距离，说明 normal prompt 的几何角色是语义可接收性锚点而非原型点。
分数分解表明，未接收比例与条件接收代价覆盖不同缺陷形态。
锚点分析表明，正确的 learned normal prompt 是接收语义成立的参考。
这些结果共同说明，异常定位的有效信号来自正常概念对局部证据的方向性解释失败，而不是异常词义本身的可枚举性。

\section{结论}

本文提出 \method{}，一种面向 \clip{} 零样本异常定位的可拒绝双曲正常性接收框架。
本文的核心观点是，异常定位的基本对象不是异常语义类，而是 normal concept 对局部证据的语义可接收性。
\method{} 用 learned normal prompt 定义语义可接收性锚点，用双曲锥刻画 normal concept 到 patch 的方向性合法特化关系，并用非平衡最优传输实现可拒绝接收。
由此得到的未接收比例和条件接收代价分别刻画正常性拒绝与高代价接收。
在 MVTec AD 和 VisA 上，\method{} 提升像素级定位结果；系统验证表明，可拒绝接收、双曲语义可接收锥、正常性参考和证据分解共同支撑了这一任务重构。
