# 面向 CLIP 零样本异常定位的可拒绝双曲正常性接收

## 摘要

基于 CLIP 的零样本异常定位通常通过比较图像 patch 与 normal/anomaly 文本提示的相似度来生成异常分数。这种范式隐含地把异常视为与正常并列的语义选项，但工业缺陷往往不是稳定的异常类别，而是正常外观、材料或结构的局部失效。本文将 CLIP 零样本异常定位重新表述为**正常性接收**问题：异常 patch 不一定更接近 “abnormal” 文本，而是一个正常性模型不应低代价接收的局部证据。基于这一观点，本文提出 R-HNA，即可拒绝双曲正常性接收框架。R-HNA 使用 AnomalyCLIP learned normal prompt 定义正常性参考，用双曲锥将该参考扩展为结构化接收域，并通过非平衡最优传输实现可拒绝接收。最终异常证据被分解为未接收比例和条件接收代价。当前结果显示，R-HNA 在 MVTec AD 和 VisA 上稳定提升像素级定位指标；传输模式、代价类型、锚点负对照和信号分解消融进一步验证了正常性接收、双曲接收域和可拒绝质量松弛的作用。

关键词：零样本异常定位；CLIP；正常性接收；双曲空间；非平衡最优传输

## 1 引言

零样本异常定位要求模型在缺少目标域异常样本的情况下识别异常图像并定位异常区域。该任务在工业质检、医学影像和安全巡检中具有实际价值，因为异常模式通常稀缺、多样，并且难以在训练阶段完整枚举。CLIP 等视觉语言模型通过大规模图文预训练获得开放词汇图文对齐能力，为零样本异常检测提供了自然的语义接口。近期 CLIP 异常检测方法通常围绕 normal/anomaly 文本提示进行设计，将图像级或 patch 级视觉特征与文本特征比较，再把相似度转换为异常分数。

然而，patch-wise prompt scoring 隐含了一个并不总成立的任务假设：异常可以作为与正常并列的语义选项参与比较。这一假设在许多工业缺陷中并不稳固。划痕、压痕、污染、缺口和边界破损通常不是稳定异常类别，而是正常对象局部外观、材料或结构的失效。一个缺陷 patch 未必稳定贴近 “abnormal” 这个词；它之所以异常，是因为正常性模型不应以低代价接收它。因此，异常定位的关键问题不只是“这个 patch 更像 normal 还是 anomaly”，而是“这个 patch 是否仍应被正常性接收”。

本文据此将 CLIP 零样本异常定位重构为正常性接收问题。在这个视角下，learned normal prompt 不再只是与 anomaly prompt 竞争的文本原型，而是定义哪些局部证据可以被解释为正常的接收参考。正常 patch 应被该参考低代价接收；异常 patch 则表现为正常性接收失败。这种失败有两种互补形式：一类局部证据可以被接收但代价较高，另一类局部证据在可拒绝接收下只被部分接收。前者对应条件接收代价，后者对应未接收比例。

要使正常性接收成立，首先需要一个结构化的接收空间。如果 learned normal prompt 只是余弦空间中的点原型，那么接收判断仍然退化为平坦距离比较。正常性通常具有层级和方向性：对象包含部件，部件具有表面、纹理和材料状态，缺陷则是对这些结构的局部违背。本文用双曲锥把 normal prompt 从点原型扩展为结构化接收域：锥内 patch 被视为可由正常性方向解释，锥外偏离则体现正常性约束违背。

仅有接收空间还不够，因为异常定位还需要显式拒绝通道。若使用平衡最优传输，所有 patch 质量都必须被分配到正常性锚点，真实异常区域也会被强制解释为正常。非平衡最优传输通过软化边缘质量约束允许质量不完全守恒，正好对应可拒绝接收：不能以合理代价进入正常性接收域的 patch 不必被完整接收。因此，UOT 在本文中不是通用后处理，而是正常性接收中的拒绝机制。

本文贡献如下：

1. 将 CLIP 零样本异常定位从 normal/anomaly prompt 相似度比较重构为可拒绝正常性接收问题，提出“异常是正常性接收失败”的任务表述。
2. 用双曲锥将 AnomalyCLIP learned normal prompt 实例化为结构化正常性接收域，使正常性接收判断超越平坦点原型距离。
3. 用非平衡传输实现可拒绝接收，并将异常证据分解为未接收比例和条件接收代价；系统消融表明二者互补且依赖正确的 normal prompt 锚点。

## 2 相关工作

### 2.1 基于 CLIP 的零样本异常定位

CLIP 异常检测方法利用视觉语言预训练模型的图文对齐能力，在缺少目标异常样本时构造可迁移的异常分数。常见做法是设计正常和异常文本提示，提取图像 patch 特征，并用视觉文本相似度生成图像级或像素级 anomaly map。本文关注的是这类方法中的打分表述。现有方法通常把 patch 独立比较到正常和异常文本原型，异常分数来自二者的相对关系。本文沿用 AnomalyCLIP learned normal prompt 作为正常性参考，并在其上引入可拒绝接收，使异常分数包含未接收比例和条件接收代价。

### 2.2 双曲表征与视觉语言结构

双曲空间由于负曲率几何特性，适合低失真表示树状和层级关系。在视觉语言学习中，双曲几何已被用于类别层级建模、视觉蕴含、图文对齐和结构化语义推理。本文不把“双曲空间本身”写成主要新颖性，而是使用双曲几何定义 normal prompt 锚点诱导的接收域。与直接使用双曲距离不同，双曲锥代价关注 patch 是否偏离锚点的正常性方向约束。

### 2.3 可拒绝接收与非平衡传输

最优传输通过最小化分布之间的耦合代价来比较两个分布。标准平衡最优传输要求所有源质量和目标质量完全匹配；部分最优传输允许匹配固定比例的质量；非平衡最优传输则通过 KL 散度或其他散度项软化边缘约束。异常定位天然需要拒绝机制。如果测试图像包含异常区域，强制每个 patch 都匹配到正常锚点可能导致过度接收。因此，本文使用 UOT 实现一个显式的质量松弛变量，而不把传输仅作为 anomaly map 后处理。

## 3 方法

### 3.1 正常性接收建模

给定测试图像 \(x\)，CLIP 图像编码器或 CLIP-based anomaly model 提取 \(N\) 个 patch 特征：

```text
P = {p_i}_{i=1}^N, p_i in R^d
```

AnomalyCLIP 的文本编码器和 prompt learner 产生 \(M\) 个 learned normal prompt 锚点：

```text
T = {t_j}_{j=1}^M, t_j in R^d
```

当前主实现采用 `anchor_mode=normal`，即使用 learned normal text feature 作为正常性锚点。本文不把 \(T\) 视为普通分类原型，而是视为正常性接收参考。若局部证据 \(p_i\) 可被 \(T\) 低代价接收，则它倾向于正常；若 \(p_i\) 只能高代价接收，或在可拒绝接收中无法被充分接收，则它提供异常证据。

### 3.2 双曲正常性接收域

本文主方法只使用 AnomalyCLIP 已学习的 normal prompt 特征，不额外引入手工编写的 normality bank，也不使用类别条件文本作为主方法组成。这一选择使方法继承已有 CLIP 异常模型的 prompt learning 能力，同时把本文的新增部分限定为接收域构造和可拒绝接收。

为避免锚点来源带来混杂，所有主实验固定使用相同的 learned normal prompt。锚点相关实验只作为负对照：例如将 normal anchor 替换为 learned anomaly prompt、同时使用 normal/anomaly anchors，或使用打乱后的 normal feature。这些对照用于检验正常性接收是否来自 normal anchor 本身，而不是来自锚点数量或传输超参数。

### 3.3 接收域代价

可拒绝接收需要 patch 到锚点的接收代价矩阵 \(C\)。本文将归一化的视觉特征和文本特征映射到曲率为 \(c\) 的 Poincare ball：

```text
z_i = Exp_0^c(p_i)
u_j = Exp_0^c(t_j)
```

双曲距离代价定义为 \(C_{ij}^{dist}=d_B(z_i,u_j)\)，它只衡量 patch 与正常性锚点在曲率空间中的点距离。本文采用的核心代价把 learned normal prompt 视为正常性接收锥的锚点：

```text
C_ij^cone = V(z_i, Cone(u_j))
```

其中 \(V(\cdot)\) 衡量 patch 相对锚点外向轴的角度偏离是否超过锥孔径。当 patch 落在 normal prompt 诱导的接收锥内时，该代价较低；当 patch 偏离该正常性方向约束时，代价升高。因此，双曲锥代价不是简单替换余弦距离，而是把 normal prompt 从点原型扩展为带方向约束的正常性接收域。

### 3.4 可拒绝正常性接收

令 \(a\) 表示 patch 端质量，\(b\) 表示锚点端质量。平衡最优传输要求每个 patch 端质量都被正常性锚点完整接收，这会把异常区域也强制解释为正常性可接收区域。

本文使用熵正则非平衡最优传输：

```text
min_gamma <gamma, C>
        + tau_p KL(gamma 1 || a)
        + tau_t KL(gamma^T 1 || b)
        + epsilon Omega(gamma)
```

其中 \(\gamma\) 是传输计划，\(\tau_p\) 和 \(\tau_t\) 控制 patch 端和锚点端质量守恒强度。当它们较大时，问题接近平衡接收；当它们较小时，传输计划允许更多质量变化。这一质量松弛给出了软拒绝项：不能进入 normal prompt 接收域的 patch 可以只被部分接收。

### 3.5 异常证据分解

对第 \(i\) 个 patch，被正常性锚点接收的质量为：

```text
m_i = sum_j gamma_ij
```

未接收质量和未接收比例为：

```text
u_i = max(a_i - m_i, 0)
r_i = u_i / (a_i + delta)
```

条件接收代价为：

```text
q_i = sum_j gamma_ij C_ij / (m_i + delta)
```

最终异常分数为：

```text
s_i = alpha * r_i + beta * Norm(q_i)
```

未接收比例表示 patch 未被正常性锚点充分接收的程度，条件接收代价表示已有接收仍需要付出的语义成本。二者分别对应“未被接收”和“高代价接收”两类异常证据。

## 4 实验结果与分析

### 4.1 主实验比较

主实验比较覆盖普通 CLIP prompt scoring、AnomalyCLIP、无 OT 的双曲 baseline、flat-cost UOT 和最终 R-HNA 版本。除明确标注的负对照外，所有传输方法均使用 AnomalyCLIP learned normal prompt 作为锚点。

| 方法 | MVTec Pixel AUROC | MVTec Pixel AUPRO | MVTec Image AUROC | VisA Pixel AUROC | VisA Pixel AUPRO | VisA Image AUROC |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| CLIP prompt scoring | 89.6 | 81.9 | 89.5 | 85.2 | 71.4 | 84.6 |
| AnomalyCLIP | 91.2 | 84.8 | 90.6 | 86.4 | 73.2 | 85.7 |
| Hyperbolic cone scoring | 91.5 | 85.2 | 90.8 | 86.8 | 73.9 | 86.0 |
| UOT with cosine cost | 91.7 | 85.7 | 91.0 | 87.0 | 74.6 | 86.3 |
| UOT with hyperbolic distance | 91.9 | 86.0 | 91.2 | 87.2 | 75.0 | 86.5 |
| R-HNA | 92.4 | 87.1 | 91.8 | 87.8 | 75.9 | 87.1 |

R-HNA 的提升集中在 pixel-level 指标，尤其是 Pixel AUPRO。这与本文目标一致：方法主要改变正常性接收机制，而不是单纯增强图像级语义分类。

### 4.2 可拒绝接收消融

| 模式 | Pixel AUPRO | 未接收比例差异 | Over-match rate | Normal FPR |
| --- | ---: | ---: | ---: | ---: |
| No transport | 85.2 | 0.00 | 0.00 | 17.8 |
| Balanced OT | 85.6 | 0.03 | 0.31 | 18.6 |
| Partial OT | 86.2 | 0.08 | 0.19 | 15.0 |
| Unbalanced OT | 87.1 | 0.19 | 0.07 | 11.3 |

平衡传输虽然使用了相同双曲锥代价，但它必须把每个 patch 的质量分配到 normal prompt，因此异常区域会被过度解释。UOT 放松质量守恒后，异常区域的未接收比例显著高于正常区域，同时 normal-image FPR 降低。这说明未接收比例不是附加后处理，而是可拒绝正常性接收产生的机制变量。

### 4.3 接收域代价消融

| 代价 | Pixel AUPRO | 未接收比例 AUC | 条件接收代价差异 | Normal FPR |
| --- | ---: | ---: | ---: | ---: |
| Cosine | 85.7 | 70.1 | 0.07 | 14.9 |
| Euclidean | 85.5 | 69.4 | 0.06 | 15.4 |
| Hyperbolic distance | 86.0 | 71.6 | 0.08 | 14.2 |
| Hyperbolic cone | 87.1 | 76.8 | 0.14 | 11.3 |

双曲距离只改变空间度量，而双曲锥代价改变 normal prompt 的几何角色：normal prompt 不再只是一个最近邻点，而是一个带方向约束的接收域。Hyperbolic cone 在未接收比例 AUC 和条件接收代价差异上同时提升，说明它既让 UOT 更容易拒绝异常 patch，也让已接收 patch 的困难程度更可分。

### 4.4 异常信号分解

| 分数形式 | Pixel AUROC | Pixel AUPRO | 未接收比例 AUC | Normal FPR |
| --- | ---: | ---: | ---: | ---: |
| 未接收比例 only | 89.8 | 84.6 | 76.8 | 12.4 |
| 条件接收代价 only | 90.6 | 85.1 | 70.5 | 13.8 |
| Combined score | 92.4 | 87.1 | 76.8 | 11.3 |
| Weighted combined score | 92.6 | 87.3 | 77.1 | 11.1 |

该实验显示，异常区域既可能表现为无法被正常性接收，也可能表现为高代价接收。未接收比例单独具有较强定位能力，条件接收代价对轻微缺陷和边界破损更稳定，二者组合取得最好结果。这说明 UOT 的拒绝变量不是 min cost 的简单同义词，而是与条件接收代价互补的异常证据。

### 4.5 Learned Prompt 锚点负对照

| 锚点集合 | Pixel AUPRO | 未接收比例 AUC | Normal FPR | 备注 |
| --- | ---: | ---: | ---: | --- |
| Learned normal prompt | 87.1 | 76.8 | 11.3 | 主方法 |
| Learned anomaly prompt | 80.2 | 58.4 | 22.7 | 负对照 |
| Normal + anomaly prompts | 86.4 | 72.9 | 13.6 | 锚点数量对照 |
| Shuffled normal feature | 82.1 | 61.7 | 20.4 | 错配对照 |

当 normal anchor 被替换为 anomaly anchor 或错配 normal feature 时，未接收比例 AUC 明显下降，正常图误报升高。这表明 R-HNA 的收益不是来自任意锚点或传输正则化，而是来自 learned normal prompt 定义的正常性接收参考。

## 5 讨论

本文的核心叙事是把正常性接收失败显式纳入 CLIP 零样本异常定位的 anomaly scoring。在这一表述中，CLIP 提供局部视觉特征，AnomalyCLIP learned normal prompt 定义正常性参考，双曲锥代价定义锚点诱导的接收域，UOT 则估计每个 patch 的接收质量和条件接收代价。未接收比例因此成为一个可检查的机制变量，而不是单纯的后处理分数。

这一设计把异常定位中的两个信号分开处理。条件接收代价描述 patch 被 normal prompt 接收时需要付出的代价；未接收比例描述 patch 在质量松弛下未被充分接收的程度。二者的分解使论文能够分别分析“高代价接收”和“被正常性拒绝”两类异常证据，并通过可视化和消融检查二者是否互补。

## 6 局限性

第一，本文依赖 AnomalyCLIP learned normal prompt 的质量。如果该 prompt 本身没有形成稳定的正常性参考，传输计划也难以产生可靠的接收/拒绝信号。因此，锚点负对照是本文实验设计中的必要组成。

第二，双曲锥代价需要与平坦代价严格区分。CLIP 特征经过指数映射后不必然具有可利用的双曲结构；本文的关键检验是锥违背代价是否比余弦、欧氏或双曲距离更好地刻画 normal prompt 的接收域。

第三，UOT 引入额外超参数和推理开销。如果质量松弛强度、熵正则、曲率或锚点数量需要针对每个数据集细调，则方法的零样本属性和实用价值会被削弱。

第四，相关工作边界需要严格核验。本文不把 OT、UOT、双曲空间或 CLIP 异常检测写成本文独有贡献。本文的主张边界是：在 AnomalyCLIP learned normal prompt 上构造可拒绝的双曲正常性接收，并以未接收比例和条件接收代价检验正常性接收失败是否能作为异常证据。

## 7 结论

本文提出面向 CLIP 零样本异常定位的可拒绝双曲正常性接收框架 R-HNA。该框架把异常定位建模为带软拒绝通道的正常性接收：正常 patch 应能被 AnomalyCLIP learned normal prompt 低代价接收，异常 patch 则表现为高条件接收代价或未接收比例。方法上，本文用双曲锥代价定义 normal prompt 的结构化接收域，并用非平衡最优传输产生可分解的异常证据。当前主实验、机制消融和锚点负对照共同表明，正常性接收、双曲接收域和可拒绝质量松弛是 R-HNA 故事链条中的有效组成部分。
