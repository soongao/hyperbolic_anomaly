# 中文文章工作区

本目录存放 R-HNA 中文文章稿和审稿记录。

## 文件

- `draft_zh.md`：中文论文稿，已按 R-HNA 正常性接收故事线改写。
- `review_request.md`：给独立审稿进程的只读审稿请求。
- `independent_review.md`：独立审稿意见，已同步为 R-HNA 术语。
- `task_plan.md`：中文稿任务记录。

## 当前写作边界

核心叙事保持为：

```text
可拒绝双曲正常性接收
```

不要把论文写成 “CLIP + 双曲空间 + OT” 的模块堆叠。论文主张是：

```text
异常 patch 是 learned normal prompt 不应低代价接收的局部证据。
```

实验解释围绕四个机制展开：

- UOT 产生可拒绝接收变量；
- 双曲锥定义结构化接收域；
- 未接收比例与条件接收代价互补；
- learned normal prompt 是必要的正常性锚点。
